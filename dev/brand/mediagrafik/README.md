# Značka MEDIAGRAFIK — soubory k nahrání

Aplikace sama žádnou značku nenese; každá instance si ji nahraje
v **Nastavení → Základní nastavení**. Tohle jsou podklady pro instanci
sprava.mediagrafik.cz (dřív byly natvrdo v `www/assets/img/`).

| Pole v Základním nastavení | Hodnota / soubor |
|---|---|
| Název firmy | `MEDIAGRAFIK` |
| Web firmy | `https://mediagrafik.cz` |
| Název pluginu | prázdné → „MEDIAGRAFIK Monitor“ |
| Složka pluginu | neměnit — `mediagrafik-monitor` (na ni odpovídají weby) |
| Logo aplikace | `logo-aplikace.svg` (s podtitulem „od MEDIAGRAFIK“) |
| Logo aplikace — tmavý motiv | `logo-aplikace-tmave.svg` |
| Logo firmy | `logo-studia.png` (PNG kvůli Gmailu a Outlooku; SVG je `logo-studia.svg`) |
| Logo firmy na tmavém | `logo-studia-na-tmavem.svg` (záhlaví PDF protokolu) |
| Ikona aplikace | `ikona.png` (1024 px, průhledné pozadí) |

`logo-studia-pdf.svg` je původní tmavá varianta loga pro PDF — aplikace ji
teď nepoužívá, je tu pro úplnost.
